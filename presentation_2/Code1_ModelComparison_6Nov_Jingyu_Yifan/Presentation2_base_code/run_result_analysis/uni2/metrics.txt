UNI2 test metrics
Label 0 = benign, label 1 = high-grade
Accuracy = (TN + TP) / N
Benign recall = TN / (TN + FP)
High-grade recall = TP / (TP + FN)
Confusion matrix rows are true labels, columns are predicted labels.
